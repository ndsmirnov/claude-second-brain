# Второй мозг: Claude Code + Obsidian

Стартовая сборка: папка заметок в Obsidian и Claude Code, который её ведёт. Ты рассказываешь, как прошёл день, а он сам раскладывает всё по заметкам: люди, планы, здоровье, деньги, дневник. В новом разговоре он уже в курсе, кто ты и что у тебя происходит.

Без кода, ставится за вечер.

## Что понадобится

- Подписка Claude (Pro или выше): Claude Code входит в неё.
- Mac. На Windows тоже работает, отличия — в конце инструкции.
- Obsidian — бесплатно, obsidian.md.
- Один вечер.

## Как поставить

1. Поставь Claude Code: открой Терминал и вставь команду установки с официальной страницы Claude Code (раздел Quickstart). Затем напиши `claude` и войди в свой аккаунт.
2. В Claude Code напиши:

   `Установи второй мозг из https://github.com/ndsmirnov/claude-second-brain`

3. Он будет спрашивать разрешения — соглашайся. Спросит, где создать хранилище: можно оставить как предложит.
4. Когда закончит — открой Obsidian → «Открыть папку как хранилище» → выбери созданную папку.
5. Закрой Терминал, открой заново, перейди в хранилище и запусти `claude` (точную команду он напишет в конце установки). Скажи: **«давай познакомимся»**.

## Что внутри

| Что | Зачем |
|---|---|
| Хранилище: `Профиль`, `Карта`, папки Люди / Планы / Здоровье / Деньги / Дневник / Входящие, шаблоны | Готовая структура: открыл — и сразу есть куда класть |
| `CLAUDE.md` хранилища | Claude в каждом разговоре сам читает твой профиль и знает, куда что записывать |
| скилл `znakomstvo` | «Давай познакомимся» — 15 минут вопросов, и профиль, люди, план месяца заполнены |
| скилл `razbor-dnya` | Рассказал день — запись в дневнике и строки в карточках людей, плане, журналах здоровья и денег |
| скилл `learn-from-correction` + хук | Говоришь «не так» — он исправляет и записывает урок, чтобы не повторять |
| скилл `handoff` | Чат разросся: «вынеси в новый чат» — короткий промт, новая сессия продолжит без потерь |
| скилл `skill-forge` | «Сделай из этого скилл» — удачный процесс упаковывается, и объяснять заново не придётся |
| RTK | Сжимает вывод команд, прежде чем он попадёт к Claude: лимиты тратятся медленнее |
| статуслайн | Строка внизу окна: насколько забит чат и сколько осталось лимита |

## Как пользоваться

- **Каждый вечер — рассказ о дне.** Текстом или голосом (диктовка Mac: дважды Fn). Не надо структурировать — просто расскажи.
- **Спрашивай про свою жизнь.** «Когда я последний раз был у врача?», «Что я обещал Саше?», «Что у меня по плану на месяц?» — он ищет в заметках, а не придумывает.
- **Кидай всё во «Входящие»** и иногда говори «разбери входящие».
- **Поправляй.** Каждое «не так» становится уроком, и правок со временем меньше.
- **Чат тупит → новый чат.** `/clear` — с чистого листа, память в заметках никуда не денется.

Это база. Как надстроить над ней полноценный трекинг жизни (оценки по сферам, итоги недель и месяцев, дашборд) — в следующих видео.

# Инструкция для Claude (выполни по порядку)

Ты ставишь пользователю второй мозг. Он может быть не разработчиком: объясняй коротко и по-русски, лишнего не спрашивай, после каждого шага одной строкой пиши, что сделано. `PKG` = папка, в которой лежит этот README (если пользователь дал ссылку на GitHub — скачай архив: `curl -sL <ссылка>/archive/refs/heads/main.tar.gz | tar -xz -C /tmp` — `PKG` = `/tmp/claude-second-brain-main`; git не нужен. Именно tar.gz: `unzip` на Mac ломает русские имена файлов).

1. **Где хранилище.** Предложи `~/Documents/Второй мозг` и спроси одним вопросом, подходит ли. Если папка уже есть и не пустая — не затирай, спроси. Запомни путь как `VAULT`.
2. **Хранилище.** `mkdir -p "VAULT" && cp -R "$PKG/vault/." "VAULT/"`. Проверь: `ls "VAULT"` показывает `Профиль.md`, `Карта.md`, `CLAUDE.md` и папки.
3. **Скиллы.** `mkdir -p ~/.claude/skills && cp -R "$PKG/skills/"* ~/.claude/skills/`. Если скилл с таким именем уже есть — не затирай молча, спроси.
4. **Общий CLAUDE.md.** Возьми `PKG/CLAUDE.md`, замени `ПУТЬ_К_ХРАНИЛИЩУ` на реальный `VAULT`. Если `~/.claude/CLAUDE.md` нет — запиши туда. Если есть — допиши в конец, ничего не удаляя.
5. **Хук правок.** `mkdir -p ~/.claude/hooks && cp "$PKG/hooks/correction-signal.py" ~/.claude/hooks/`. В `~/.claude/settings.json` добавь в `hooks.UserPromptSubmit` запись из `PKG/hooks/settings-snippet.json`, **сохранив всё, что там уже есть** (сначала прочитай файл, потом аккуратно слей JSON; проверь `python3 -m json.tool ~/.claude/settings.json`).
6. **Obsidian.** `ls /Applications/Obsidian.app`. Нет — если есть Homebrew (`which brew`), `brew install --cask obsidian`; иначе попроси скачать с obsidian.md. Скажи: открыть Obsidian → «Открыть папку как хранилище» → `VAULT`.
7. **Обвесы (спроси одним вопросом, ставить ли — экономят лимиты).**
   - RTK: нужен Homebrew. Нет — попроси вставить в Терминал команду с https://brew.sh (нужен пароль Mac, сам ты его ввести не сможешь), после установки выполни строки, которые brew напечатает в конце. Затем `brew install rtk && rtk init -g`, проверка `rtk --version`.
   - Статуслайн (github.com/AndyShaman/claude-statusline): `which jq || brew install jq`, `cp "$PKG/statusline/statusline.sh" ~/.claude/statusline.sh && chmod +x ~/.claude/statusline.sh`, в `~/.claude/settings.json` через `jq` поставь `"statusLine": {"type": "command", "command": "bash ~/.claude/statusline.sh"}`, остальное не трогая. Предупреди: macOS может спросить доступ к связке ключей — «Разрешить всегда».
8. **Проверка.** `ls ~/.claude/skills`, `ls "VAULT"`, `python3 -m json.tool ~/.claude/settings.json >/dev/null && echo ok`.
9. **Финал.** Напиши пользователю ровно это: закрыть Терминал, открыть заново, выполнить `cd "VAULT" && claude` (с реальным путём) и сказать «давай познакомимся».

**Windows:** вместо `~/.claude` — `%USERPROFILE%\.claude`, хранилище — `Документы\Второй мозг`, копировать через PowerShell `Copy-Item -Recurse`. RTK и статуслайн пропусти (рассчитаны на Mac), остальное так же. Хук запускается через `python` — если Python не установлен, пропусти шаг 5 и скажи об этом.
