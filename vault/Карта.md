# Карта хранилища

| Папка / файл | Что там | Как называть файл |
|---|---|---|
| `Профиль.md` | кто я, главные люди, цели, как со мной говорить | — |
| `Дневник/` | один файл на день: что было, с кем, состояние | `YYYY-MM-DD.md` |
| `Люди/` | карточка на человека: кто это, история по датам | `Имя Фамилия.md` |
| `Планы/` | цели на год, план на месяц, идеи «на потом» | `Цели YYYY.md`, `YYYY-MM План.md`, `Идеи.md` |
| `Здоровье/` | журнал: сон, вес, спорт, самочувствие, врачи | `Журнал здоровья.md`, отдельный файл на большую тему |
| `Деньги/` | цели, крупные траты и решения, долги | `Журнал денег.md`, `Цели по деньгам.md` |
| `Входящие/` | всё, что пока непонятно куда: ссылки, мысли, файлы | любое; при разборе — разнести по папкам |
| `Шаблоны/` | заготовки новых файлов | — |

Новая папка появляется, только когда тема выросла (5+ заметок) и я сказал «да».
