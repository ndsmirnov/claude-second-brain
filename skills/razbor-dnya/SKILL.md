# razbor-dnya — разбор дня

Цель: человек рассказал день как есть, а хранилище само обновилось, и в следующем разговоре Claude это уже знает.

Это базовый разбор. Он ничего не оценивает и не анализирует, только аккуратно раскладывает по местам. Оценки, сферы жизни и итоги недель/месяцев — следующий уровень, его можно надстроить потом.

## ⛔ Правила
- Только факты из рассказа, по возможности его же словами. Не додумывай мотивы, чувства и выводы.
- Не спрашивай по каждой мелочи. В конце максимум 1–2 вопроса, если без ответа запись будет неверной (кто такой «Саша», если Саш двое).
- Не создавай карточку человека молча, если он упомянут вскользь. Заводи, если человек важный или сам пользователь попросил; иначе — просто имя в дневнике.
- Ссылка на человека — `[[Имя Фамилия]]`, ровно одна на упоминание, без вложенных ссылок.

## ШАГ 0 — Контекст
Ты внутри хранилища (иначе путь — строка «Моё хранилище:» в `~/.claude/CLAUDE.md`). `Профиль.md` и `Карта.md` уже подгружены через `CLAUDE.md` хранилища. Дата — сегодняшняя, если человек не сказал другую («вчера» → вчерашняя).

## ШАГ 1 — Дневник
`Дневник/<YYYY-MM-DD>.md` по шаблону `Шаблоны/День.md`. Если файл за этот день уже есть — дополняй, не перезаписывай. Энергию и настроение ставь, только если человек их назвал.

## ШАГ 2 — Разнести по папкам
Для каждого факта из рассказа:
- **Человек** → найти карточку в `Люди/` (поиск по имени и полю «как зовут ещё»). Есть — строка в «История»: `- YYYY-MM-DD — что было ([[Дневник/YYYY-MM-DD]])`. Новое «важно помнить» (день рождения, договорённость) — в тот раздел.
- **План** → в `Планы/<YYYY-MM> План.md`: сделанное — отметить `[x]`, новое намерение — добавить задачей. Не на этот месяц — в `Планы/Идеи.md`.
- **Здоровье** (сон, спорт, вес, еда, самочувствие, врач) → строка в `Здоровье/Журнал здоровья.md`.
- **Деньги** (крупная трата, доход, решение, долг) → строка в `Деньги/Журнал денег.md`. Мелочь не пишем.
- **Важное надолго** (новая работа, переезд, расставание, новая цель) → обновить нужный раздел `Профиль.md`.
- Раздел «Сейчас в жизни» в профиле — поправить, если день что-то в нём изменил (3–5 строк, не больше).

## ШАГ 3 — Ответ
Коротко:
1. Что записано куда — список «файл — что добавлено», по одному на строку.
2. Одно наблюдение, только если оно прямо следует из записей (например, «третий день подряд пишешь, что не выспался»). Не мораль и не совет без просьбы.
3. Вопросы, если остались (максимум 2).
